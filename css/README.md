# Voyager 디자인

로그인, 메인, 대기실, 프로필, GM 화면은 `style.css`를 연결합니다. `style.css`는 아래 파일들을 불러오는 공통 진입점입니다.

| 파일 | 역할 |
| --- | --- |
| `station.css` | 색상 변수, nebula 배경, 헤더·푸터, 버튼, 입력창, 공통 상태 표시 |
| `access.css` | 로그인 화면, 접속 패널, 궤도 장식 |
| `command.css` | 배틀룸 목록과 챔버 카드 |
| `lobby.css` | 대기실, 트레이너·관전자, 교체 요청, 프로필 팝업 |
| `profile.css` | 트레이너 카드, 파티 슬롯, 포켓몬 검색창 |
| `admin.css` | GM 로그인과 서버 로그 |
| `motion.css` | 패널 등장, 궤도 회전, 상태 표시등, 챔버·READY 효과, 슬롯 로딩 |
| `intro.css` | 기존 배틀 인트로의 우주 테마 |
| `select.css` | 기존 포켓몬 선택 화면의 우주 테마 |

주요 색상은 `station.css`의 `:root`에서 조정할 수 있습니다. 배경 경로는 CSS 파일 기준 `../img/nebula.jpg`입니다. 모바일 배치와 키보드 포커스, 동작 줄이기 설정을 지원합니다.

프로필은 PC에서 사진과 파티를 좌우로 배치하고, 800px 이하에서는 위아래로 전환합니다. 600px 이하에서는 파티 슬롯이 2열로 표시됩니다. 대기실의 프로필 팝업(`embed=1`)과 다른 트레이너의 읽기 전용 카드도 같은 반응형 스타일을 사용합니다.

메인 제목의 세 줄은 `js/typewriter.js`에서 순서대로 타이핑합니다. 각 요소의 `data-typewriter-speed` 값은 글자당 밀리초이며, 값을 낮추면 빨라집니다. 텍스트의 공간을 미리 확보해 타이핑 중에도 화면 배치가 유지됩니다. 동작 줄이기 설정에서는 전체 문장을 바로 표시합니다.

`battleroom.css`와 기존 기능 JavaScript는 수정하지 않았습니다. `games/battleroom1.html`부터 `3.html`까지는 원래 비어 있으며, 실제 배틀 화면의 마크업과 기능 연결은 이 디자인 작업에 포함하지 않았습니다. 배틀 화면을 구성할 때는 `battleroom.css`의 기존 전역 스타일과 공통 스타일의 충돌을 확인해야 합니다.
